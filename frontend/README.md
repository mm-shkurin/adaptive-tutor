# Frontend

React 19 frontend with Feature-Sliced Design.

## Structure
- `src/pages/` — Screens (Chat, Quiz, Progress, Documents)
- `src/widgets/` — Reusable components
- `src/features/` — Feature-level logic
- `src/shared/` — Shared utilities

## Setup
```bash
npm install
npm run dev
```

## Test
```bash
npm run test
npm run test:e2e
```
