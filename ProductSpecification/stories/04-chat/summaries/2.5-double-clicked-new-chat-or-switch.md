## implementation (2026-11-20)

**Quirk:** `startNewChat` and `chooseDocument` needed `createLock` / `switchLock` like `sendLock`; double-activating the switch button alone only opens the picker twice, so the stored effect is asserted on a double-clicked document choice.
**Impact:** UI 2.5 double-clicks the choice after opening the picker, not only the switch control.
