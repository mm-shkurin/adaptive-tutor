## tests (2026-11-19)

**Mistake:** Two sequential Selenium `click()` calls on choice/tell after the first re-render hit `StaleElementReferenceException`.
**Why it failed:** The first click updates the thread DOM; the stored WebElement is gone before the second click.
**Better approach:** `driver.execute_script("arguments[0].click(); arguments[0].click();", el)` so both clicks fire on the same node without a re-find gap.
