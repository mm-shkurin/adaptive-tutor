## implementation (2026-11-19)

**Decision:** Re-choice with no open examiner question returns the last grade in the HTTP body but does not append chat lines (`Attempt.persist=False`; attempt row still records those line ids for idempotent replay).
**Why:** `commit_attempt` always appended attempt lines, so returning the prior grade would duplicate the row (or collide on id).
**Alternatives considered:** Empty 200 body (fails “returns previous grade”); skip `commit_attempt` entirely (breaks attempt-key replay).
