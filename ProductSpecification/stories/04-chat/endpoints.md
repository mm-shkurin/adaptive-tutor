# Чат — API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | /api/v1/chats | Свои чаты, сначала новые. Имя документа и последняя реплика человека |
| POST | /api/v1/chats | Новый пустой чат: выбранный готовый PDF или самый новый |
| POST | /api/v1/chats/open | Чат выбранного PDF: самый новый уже существующий или новый пустой. Остальные чаты не меняются |
| GET | /api/v1/chats/{id} | Лента своего чата. Это открытие, на котором готовый PDF без векторов получает их |
| POST | /api/v1/chats/{id}/messages | Одна попытка: реплика, вопрос Экзаменатора, выбор или «сказать ответ» |

## Notes

- Скрепка запроса не шлёт. Она открывает «Документы».
- `POST /api/v1/chat/messages` остаётся удержанием приёмки истории 2 и не является репликой студента.
- Размер страницы списка не выбран. В ответе только свои чаты.
- Повтор того же `Idempotency-Key` не добавляет вторую реплику. Новый ключ — новая попытка.
