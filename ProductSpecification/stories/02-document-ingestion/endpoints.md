# PDF-документы — API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | /api/v1/documents | Свои документы, сначала новые, не больше 50 на страницу |
| POST | /api/v1/documents | Принять PDF и сразу вернуть строку «Ждёт» |
| GET | /api/v1/documents/{id} | Один свой документ. Чужой и отсутствующий неразличимы |

## Notes

- Поиска по тексту здесь нет. Куски в ответ не входят. Чат — другая история.
- Дверь «Создать презентацию» на экране есть, запроса у неё в этой истории нет.
- Повтор того же `Idempotency-Key` — тот же документ и не шестая загрузка. Новый ключ — новый документ, даже если байты те же.
