## green-selenium (2026-10-26)

**Quirk:** Indexing finishes in one usecase turn, so the UI can miss «В процессе» unless the memory intake pauses while status is indexing under a probe.
**Where:** `backend/adapters/memory/document_intake.py` (`indexing_hold_seconds` via `IndexProbe`), poll in `useDocumentsScreen.js`
**Implication:** Frontend upload scenarios that assert «В процессе» need the acceptance probe hold; production has no artificial pause.

## green-frontend (2026-10-26)

**Decision:** While any row is waiting or indexing, the screen polls GET `/api/v1/documents` every 250ms.
**Why:** Upload returns waiting immediately; status advances only on the server.
**Where applied:** `frontend/src/features/documents/useDocumentsScreen.js`
