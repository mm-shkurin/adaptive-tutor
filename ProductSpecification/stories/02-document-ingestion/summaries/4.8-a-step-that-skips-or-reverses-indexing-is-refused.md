## design (2026-11-09)

**Decision:** `Document.transition` allows only waiting→indexing and indexing→ready|failed; any skip, reverse, or move from ready/failed raises `InvalidStatusTransition` (HTTP 409).
**Why:** Finished docs used to no-op and return 200, which looked like a stay but was not a refusal.
**Where applied:** `backend/domain/document/document.py`; acceptance `/move`; browser fixture seeds failed via `IndexProbe.force_failed_document` instead of an illegal waiting→failed move.
