**Decision:** Ready-row size is `(size_bytes / 1024²).toFixed(1) + ' MB'` with meta `N стр.` / `N чанков`.
**Why:** OpenAPI leaves display formatting to the screen; mockup `04-ready` uses one decimal MB.
**Where applied:** `frontend/src/features/documents/logic/libraryView.js`

## green-selenium (2026-10-26)

**Quirk:** Seeding a ready PDF for the browser releases indexing, then `hold_indexing()` so a later upload can stay «Ждёт».
**Where:** `acceptance/statements/signed_in_browser_statements.py`, `acceptance/clients/application/index_probe.py`
**Implication:** Any UI scenario that uploads after a ready seed must re-release indexing when status should advance.
