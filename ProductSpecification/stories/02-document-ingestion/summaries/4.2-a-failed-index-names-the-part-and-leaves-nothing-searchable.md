## design (2026-11-09)

**Decision:** A mid-index failure after a successful PDF read goes through `IndexDocuments._refusal` → `_fail(reason)`; the reason names the failed part (the table markdown).
**Why:** Tables are not a separate store step; the named failure is the refusal after text was read, before pieces are written.
**Where applied:** `backend/usecase/document/index_documents.py`, `ProbeIndexDocuments`, `FakeIndexDocuments`

## green-acceptance (2026-11-09)

**Surprise:** Unskipping the acceptance test was already green — table failure lived in `ProbeIndexDocuments._refusal` and `_fail` already deleted the file.
**Why:** Earlier RED skip assumed ready; the hook path was finished with later indexing work.
**Impact:** This slice is usecase coverage + enabling the acceptance scenario, not a new worker algorithm.
