## green-usecase (2026-10-21)

**Mistake:** `IndexDocuments` deletes the file of every document it finishes, including the neighbour indexed in the Given.
**Why wrong:** The scenario then asserts the neighbour PDF bytes are still stored. That neighbour already passed through `index_waiting`, so the file is gone before the person's file is deleted.
**Correct location/approach:** The neighbour's pieces and file have to be present without that delete. Only the document just indexed loses its file.

## green-usecase (2026-10-21)

**Decision:** After a neighbour finishes indexing, their file is already gone and their pieces remain.
**Why:** The worker deletes the file of every document it finishes, so a later check cannot still see that PDF.
**Where applied:** indexing-worker ADR and scenario 4.1.
