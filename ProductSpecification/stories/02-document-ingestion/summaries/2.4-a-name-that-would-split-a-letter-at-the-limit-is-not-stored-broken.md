## design (2026-11-09)

**Decision:** The 255 name limit is NFC grapheme clusters; storage is `Text`, not `VARCHAR(255)`.
**Why:** A combining mark at the edge is two code points and one letter; a code-point cap would refuse or cut it.
**Where applied:** `backend/domain/document/file_name.py`, migration `0006`, `DocumentRow.name`, `documents.yaml`

## adapters-discovery (2026-11-09)

**Surprise:** Acceptance already passed on memory intake while Postgres `String(255)` would still reject a 256-code-point grapheme-safe name.
**Why:** `AcceptanceServer` wires `MemoryDocumentIntake`, which has no column length.
**Impact:** Name-length scenarios need a storage round-trip (or live Postgres) to catch the VARCHAR cut.
