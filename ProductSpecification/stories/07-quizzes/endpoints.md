# Викторины — API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | /api/v1/quizzes | Свои викторины, сначала новые. Имя документа, тема, число вопросов, прошлый завершённый счёт |
| POST | /api/v1/quizzes | Создать: поиск кусков, один вызов модели, запись и открытый заход с первого вопроса |
| GET | /api/v1/quizzes/{id} | Своя викторина: вопросы без верного индекса до выбора; открытый заход или результат |
| POST | /api/v1/quizzes/{id}/answers | Выбор варианта на текущем вопросе открытого захода |
| POST | /api/v1/quizzes/{id}/advance | «Далее» или завершение после ответа на текущий вопрос |
| POST | /api/v1/quizzes/{id}/retries | Новый заход с первого вопроса тех же вопросов, без вызова модели |

## Notes

- `Idempotency-Key` на `POST /api/v1/quizzes`: повтор того же ключа не создаёт вторую викторину.
- Верный индекс в ответе клиенту — только после выбора или на экране результата.
- Размер страницы списка: не больше 100 своих викторин за ответ (новые сверху).
