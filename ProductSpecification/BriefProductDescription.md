# AdaptiveTutor — Brief Product Description

## What

AdaptiveTutor — агентная мультимодальная RAG-система для обучения. Система "читает" лекции, учебники, слайды, методички (включая формулы, таблицы, графики) и помогает студентам учиться через интерактивный диалог с AI-агентами.

## Target Users

- Студенты (основные пользователи)
- Преподаватели (загружают материалы, создают тесты)
- Администраторы (управляют пользователями, контентом)

## Core Value Proposition

Не просто отвечает на вопросы, а **учит**:
- Объясняет с ссылками на источники (слайды/страницы)
- Задаёт наводящие вопросы (сократический метод)
- Генерирует персональные тесты по теме
- Отслеживает знания студента (Knowledge Tracer)
- Адаптирует объяснения под уровень (профессор / пятилетний)

## Key Features

### 1. Multimodal Document Ingestion
- PDF, PPTX, DOCX
- Извлечение текста, таблиц (Camelot), изображений (CLIP), формул (LaTeX)
- Индексация в векторную БД

### 2. Agent Pipeline
- **Planner** — разбирает вопрос (факт/определение/задача/сравнение)
- **Retriever** — ищет по тексту, таблицам, изображениям, формулам
- **Explainer** — объясняет с цитатой на источник
- **Quizmaster** — генерирует 3-5 вопросов по теме
- **Critic** — проверяет на галлюцинации
- **Knowledge Tracer** — ведёт профиль студента

### 3. Learning Modes
- "Объясни как профессор" / "Объясни как пятилетнему"
- "Экзаменатор" — агент задаёт вопросы, оценивает ответы
- "Сократический диалог" — подводит к ответу, не даёт его напрямую

### 4. Student Progress Tracking
- Граф знаний (Force-directed graph)
- Слабые темы → визуально выделены
- История сессий
- Аналитика по времени и темам

## MVP Scope

**v1 (MVP):**
- Document ingestion (PDF, базовый retrieval)
- Chat agent (Planner + Retriever + Explainer)
- Simple quiz generation
- Knowledge Tracer (базовый профиль)

**Future:**
- Full multimodal (формулы, изображения)
- Интеграция с LMS (Moodle/Canvas)
- Коллаборативное обучение
- Мобильное приложение

## Non-Goals (MVP)

- Voice input/output
- Видео-лекции
- Real-time collaboration
- Gamification
